## Run notebooks locally

```powershell
python -m pip install -r requirements.txt
```

Open the desired `.ipynb` in VS Code or Jupyter and select your Python kernel. Keep any referenced CSV files in the location expected by the notebook; Day 05 data is stored in `Day05_Pandas/` and can be copied into a working folder when needed.

## Power BI status
`Day13_PowerBI/Day13_Day14_Retail_Sales_Dashboard.pbix` is an existing **starter** Power BI file.
