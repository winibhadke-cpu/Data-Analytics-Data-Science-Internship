# Run in VS Code (Windows)
1. Extract ZIP and open the **Day20_Foundation_Mini_Project** folder via File > Open Folder.
2. Terminal > New Terminal.
3. Run `py -m venv .venv`.
4. Run `.\.venv\Scripts\python.exe -m pip install -r requirements.txt`.
5. Install VS Code extensions **Python** and **Jupyter** if prompted.
6. Open `notebooks/Day20_Foundation_Mini_Project.ipynb`.
7. Top right > Select Kernel > Python Environments > `.venv`.
8. Click **Run All**, wait for results, press Ctrl+S.
9. For SQL, open Workbench, create schema/table using the SQL script, import the raw CSV, then execute queries.
10. For Power BI, follow `powerbi/PowerBI_Dashboard_Build_Guide.md` and save PBIX locally.
11. For GitHub: create empty repo, run `git init`, `git add .`, `git commit -m "Day 20 mini project"`, `git branch -M main`, `git remote add origin https://github.com/YOURUSERNAME/day20-retail-analytics.git`, `git push -u origin main`.
12. Screenshot notebook output, SQL results, and Power BI canvas for institute proof.
