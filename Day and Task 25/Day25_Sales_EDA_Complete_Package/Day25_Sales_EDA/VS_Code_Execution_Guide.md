# Day 25 execution
1. Extract ZIP and open Day25_Sales_EDA in VS Code.
2. Install Microsoft Python and Jupyter extensions.
3. Open Terminal and run:
```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```
4. Open Day_25_Sales_EDA.ipynb. Select Kernel > Python Environments > .venv.
5. Click Run All, then Ctrl+S. Charts and summaries are regenerated in the project folder.
6. Review profit limitations and verify totals.
