# Day 26 execution
Extract ZIP and open folder in VS Code. Install Python and Jupyter extensions. Open Terminal and run:
```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```
Open Day_26_Customer_Analysis.ipynb, select .venv kernel, click Run All, then Ctrl+S. CSVs and charts regenerate in the project folder.
