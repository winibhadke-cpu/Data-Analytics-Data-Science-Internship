# Run Day 33 in VS Code (Windows)
1. Extract the ZIP into your internship folder.
2. Open VS Code > File > Open Folder > Day33_Business_Insights.
3. Install Microsoft Python and Jupyter extensions.
4. Open Terminal > New Terminal. Run `python -m venv .venv` then `.\.venv\Scripts\python.exe -m pip install -r requirements.txt`.
5. Open Day_33_Business_Insights.ipynb. Select Kernel > Python Environments > .venv.
6. Click Run All. Keep the notebook working directory at the extracted folder.
7. Confirm all PASS checks and 17 insights. Business_Insights.csv and visualizations are regenerated.
8. Save the notebook. Submit the Word report; retain PDF and ZIP for Day 35. Day 28 stays pending.
